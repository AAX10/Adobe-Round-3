# H-D4: Uncorroborated Factual Claim Deficit

**Failure Mode:** Quantitative claims lack structured citations or independent anchors.
**Severity:** Medium

## 1. Core Assumption
Large Language Models have been specifically RLHF-tuned to distrust unbacked quantitative claims to combat hallucination and marketing inflation. When an LLM ingests "We have 10,000+ enterprise clients", it looks for structured backing.

## 2. Technical Failure Mode
The DOM contains aggressive quantitative claims (dollar amounts, user counts, percentages) but the underlying schema provides zero `citation` properties, `Review` aggregates, or external reference links.

## 3. Severity & Rationale
* **Medium**: The entity is not penalized directly, but the claims are effectively ignored or down-weighted during retrieval-augmented generation (RAG).

## 4. Validation Methodology
1. Run a Regex heuristic over the raw DOM text to identify quantitative assertion patterns (e.g., `\d+%`, `\$\d+`, `\d+ users`).
2. Scan the JSON-LD payload for corresponding `citation`, `Review`, or `AggregateRating` properties.
3. Flag if heavy assertions exist in a vacuum of structural evidence.

## 5. Remediation Path
If citing statistics, include RDF citations pointing to independent studies, press releases, or official filings within the page's metadata payload.
