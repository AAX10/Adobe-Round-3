# H-D3: Cross-Modal Attribute Contradiction

**Failure Mode:** Schema name mismatches visible DOM, lowering data confidence.
**Severity:** High / Medium

## 1. Core Assumption
Modern AI search engines use multi-modal corroboration. They compare what is declared invisibly in the metadata (JSON-LD) against what is presented to the human user in the visual DOM (H1, Title tags).

## 2. Technical Failure Mode
The `Organization.name` in the structured data is vastly different from the `<title>` or `<h1>` of the page. This often happens when developers copy-paste template schemas but update the visible content.

## 3. Severity & Rationale
* **High** if the string distance is severe (e.g., Jaro-Winkler similarity < 0.40). AI models classify this as deceptive/spam.
* **Medium** if the variance is moderate.

## 4. Validation Methodology
1. Extract the `Organization.name` from the JSON-LD.
2. Extract the page `<title>` and main `<h1>`.
3. Normalize strings (lowercase, strip corporate designations like LLC/Inc).
4. Compute the Jaro-Winkler string similarity distance.

## 5. Remediation Path
Synchronize the brand naming convention across visual UI elements and the metadata layer.
