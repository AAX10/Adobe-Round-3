# H-D2: External Identity Grounding Deficit

**Failure Mode:** Lack of Wikidata/authoritative `sameAs` links causes entity conflation, compounded by Domain Drift.
**Severity:** Critical / High

## 1. Core Assumption
Machine Learning models rely on highly authoritative, human-curated registries (like Wikidata, Wikipedia, or financial registries) as foundational "anchors" to verify an entity's existence and differentiate it from similarly named entities.

## 2. Technical Failure Mode
* **Missing Anchors:** The `sameAs` array only contains social media links, omitting globally unique identifier graphs like Wikidata Q-IDs.
* **Broken Links (404):** The provided URLs do not resolve.
* **Domain Drift (Anti-Spoofing):** The provided authoritative URL redirects to a completely unexpected, out-of-domain endpoint, raising immediate spoofing flags within AI trust models.

## 3. Severity & Rationale
* **Critical** if Domain Drift is detected, as this mimics malicious SEO/spoofing tactics.
* **High** if no Knowledge Graph anchors are present, significantly lowering the confidence threshold for the entity.

## 4. Validation Methodology
1. Parse the `sameAs` array for known high-authority domains.
2. Issue an HTTP `HEAD` / `GET` request to verify liveness.
3. Compare the originating domain against the resolved HTTP redirect chain to identify Domain Drift.

## 5. Remediation Path
Audit and prune dead links from the `sameAs` payload. Prioritize adding exact Wikidata (`https://www.wikidata.org/wiki/Q...`) and Wikipedia references.
